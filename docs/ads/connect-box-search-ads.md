# Connect Box 検索広告：事務／オンライン秘書向け（初月）

## 使うURL
- **広告の遷移先**: `/connect-box/ads/back-office`（新LP）  
  - `noindex, nofollow`（検索に出さない）  
  - サイトマップ非掲載・サイト内ナビからもリンクしない  
  - 計測: `back_office_ads_inquiry` / `back_office_ads_diagnostic`
- **通常の公開LP**: `/connect-box/back-office`（**現行の古い事務代行LPのまま**。索引可）

方針: 採用代行には振らず、**事務代行・オンライン秘書（費用・比較）**で学習する。差別化は安さではなく人選・顔合わせ・代表設計・売上事務特化。

## 除外キーワード（必須）
- 求人、転職、在宅ワーク、副業、パート、派遣、未経験
- 無料、稼げる、登録だけ
- テンプレート、書き方、とは、意味
- フジ子さん（ブランド除外は任意。比較流入を取るなら外さない）

## 最初の1ヶ月：予算配分の目安
- 週予算を固定し、**メイン語群で学習**（CV=無料トライアル申込／`generate_lead`）
- CPAが想定（目安6〜8万円/問い合わせ）を大きく超えた語は停止
- 「おすすめ」「オンライン秘書」単体は求人ノイズが出やすい → 検索語句を毎日確認

## 検証指標
1. CTR（広告文の当たり）
2. LP到達後の診断完了率（`diagnostic_complete`）
3. 申込率（`generate_lead` / `back_office_ads_inquiry`）
4. トライアル開始率・有料化率（オフラインで追う）

## 広告文の軸（例）
- 見出し: オンライン秘書 月8万円から
- 見出し: 2週間無料｜顔合わせして開始
- 説明: アポ・返信・追客まで。人材業界10年が人選。安さではなく続く体制。

## やらないこと（初月）
- 採用代行／応募者対応への本予算投下（許可・実績確認後）
- SNS運用代行・MEOへの寄せ（獲得は安いが継続単価が合いにくい）
