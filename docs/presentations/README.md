# バックオフィス初回商談資料 — 使い方

## ファイル

| ファイル | 用途 |
|---------|------|
| `backoffice-deck.html` | ブラウザ表示・**PDF出力**（デザイン済み12枚） |
| `backoffice-deck.md` | **Googleスライド**へのコピペ原稿 |

---

## PDFとして保存する

サイトのナビやLPからはリンクしていません。URLを知っている人だけ開けます（検索にも出さない設定です）。

1. 開発サーバーを起動（`npm run dev`）し、以下のURLをChromeで開く：
   **http://localhost:5174/lp/back-office/deck**
2. 本番でも同じ階層です： **https://（公開ドメイン）/lp/back-office/deck**
3. 右上の **「PDFとして保存（印刷）」** をクリック
4. 送信先：**PDFに保存**
5. 用紙サイズ：**横（Landscape）**
6. 余白：**なし**
7. 背景のグラフィック：**オン**

→ 12枚のPDFが1ファイルに出力されます。

---

## ヒアリング内容を資料に反映する

1. 資料ページ右上の **「ヒアリングを記入」** を開く
2. 御社名・困っていること・Phase案などを入力する
3. 入力と同時に、表紙・スライド3（状況）・スライド8（Phase提案）・スライド11（次のステップ）が更新される
4. 内容はこのブラウザに保存される。別の会社向けに使うときは「空欄に戻す」

PDF出力時は入力パネルは印刷されません。Googleスライドへは、反映後の内容をコピペしてください。

---

## Googleスライドにする

1. Googleスライドで新規プレゼンテーションを作成
2. スライドサイズ：**ワイド画面 16:9**
3. `backoffice-deck.md` を開き、`---` ごとに1スライドずつコピペ
4. テーマカラー（参考）：
   - メイン： `#4a5ba8`
   - アクcent： `#e8941a`
   - 文字： `#152238`

### 商談後に更新するスライド

- **スライド3** — 御社の状況（ヒアリングメモ）
- **スライド8** — Phase提案（御社向け開始案）

---

## ターゲット（想定）

- 従業員 **10〜50名** の中小企業
- 経理・総務が **社長または1〜2名** で回している
- 採用は増やしたくないが、**業務量・属人化** に課題がある

---

## 商談の進め方（参考）

1. スライド2でゴールを共有（5分）
2. スライド3を空欄のままヒアリングし、右上のフォームへ入力（10分）
3. スライド4〜7でサービス説明（15分）
4. スライド8のPhase案を口頭で擦り合わせ、後日更新（10分）
5. スライド9〜11で流れ・FAQ・次ステップ（5分）

合計 **約45分** を想定。

---

## カスタマイズのコツ

- **Phase 1** は必ず「小さく始める」内容に（請求・入金など定型業務）
- 数字（週8h→2h等）は「イメージ」と必ず断り、御社の数字は後日提示
- 次回日程とPhase案送付日をスライド11に必ず記入してから送付
