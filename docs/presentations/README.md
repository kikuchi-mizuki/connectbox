# Connect Box｜初回商談資料（課題起点）

## 方針

- Connect Box **全体**の初回資料
- 入口は **課題タイプ**（まずは5つ）
- 課題タイプは **管理画面で追加・編集**できる

## URL

| 用途 | URL |
|------|-----|
| 資料 | http://localhost:5174/connectbox/back-office/deck |
| 管理 | http://localhost:5174/connectbox/back-office/deck-admin.html |

## 初期の課題タイプ（5つ）

1. 集客・営業が止まっている → 営業・集客支援パック
2. 経理・事務が圧迫している → バックオフィス安定化パック
3. 立ち上げで手が回らない → 立上げ一式パック
4. 属人化・欠員が怖い → 仕組み化・引き継ぎパック
5. 採用したくないが仕事は増えている → 必要分だけ外部化パック

## 管理の流れ

1. 管理画面で課題／プランを編集
2. 「ブラウザに保存」→ 同じPCの資料に即反映
3. 「JSONダウンロード」→ `public/connectbox/back-office/deck-content.json` を差し替えて共有
