# こんなお悩み、ありませんか

1. **本業に手が回らない** — 経理や総務に時間が取られている
2. **属人化** — 担当者しか分からない業務がある
3. **繁忙期の対応** — 月初・決算期だけ業務量が増える
4. **コストの見直し** — 採用は増やしたくないが、業務量は多い

> 人を足すほどではないが、社内の時間が事務に取られている——そんな相談から始まっています。

# なぜ Connect Box に任せられるか

**3,000名以上の実務経験者から、御社に合う人材をアサイン**

- 大手企業での勤務経験を持つ人材
- 経理・総務・営業事務などの**実務経験**
- 業務量に合わせた**柔軟なアサイン**

> 請求・経費・営業事務など、繰り返し発生する業務から外に出せます。
