# こんなお悩み、ありませんか

1. **本業に手が回らない** — 経理や総務に時間が取られている
2. **属人化** — 担当者しか分からない業務がある
3. **繁忙期の対応** — 月初・決算期だけ業務量が増える
4. **コストの見直し** — 採用は増やしたくないが、業務量は多い

> 人を足すほどではないが、社内の時間が事務に取られている——そんな相談から始まっています。
